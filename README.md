# Library Management System

A desktop-based Library Management System developed using Python and Tkinter.

This application provides an easy-to-use graphical interface for managing books, members, and borrowing operations.

---

## Features

### Book Management

- Add new books
- Remove books
- Track available copies
- Search books
- Manage book information


### Member Management

- Register new members
- Store member information
- View members


### Borrow System

- Borrow books
- Return books
- Track borrowed books
- Calculate late return penalties

### Data Persistence

- Automatically saves data using JSON
- Restores data after restarting the application
